# PipeWire audio output plugin

This plugin sends OxiGuitar's sound to your speakers through PipeWire, the sound system of current Linux desktops.

It uploads nothing and downloads nothing. It only plays sound on your computer.

It has the lowest latency of the Linux outputs. Where PipeWire isn't running, install the ALSA output plugin as well, so OxiGuitar has something to fall back on.
